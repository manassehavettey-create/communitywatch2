# Folio — image assets for Google Flow

20 images. Each prompt below is complete: paste it into Google Flow as is, generate, export at the listed size, and save it at the listed path. Until an image exists, Folio shows a typographic fallback, so nothing breaks while you work.

A copy-button version of this list is published as an artifact (link in the chat).
